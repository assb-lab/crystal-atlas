# Crystal Atlas — 結晶構造の関係地図

結晶構造を、**空隙占有・原子の規則化・歪み・積層・群–部分群関係**から探索するインタラクティブアトラスです。React + TypeScript で実装し、[Vite+](https://viteplus.dev/)（`vp`）でビルド・テスト・整形・lint を行います。

主な表示は **Family（分類）・Derivation（構造派生、既定）・Symmetry（対称性）** です。LadybugDB/WASMで、同じ出典付き知識グラフをブラウザ内から照会します。既存の充填ツリー・模型・比較も利用できます。範囲を選んだ文献照合、抽出候補・採否履歴、文献別分類、限定した理想模型の対称性検証を登録しています。文献全文の網羅抽出は未実施です。スキーマ・配布・検証と制約は[知識グラフ基盤](docs/KNOWLEDGE_GRAPH.md)を参照してください。

開発は **Issue → developからfeatブランチ → develop向けPR** の順で進めます。developからmainへの昇格は、ユーザーの指示を受けて別のPRで行います。詳細は [AGENTS.md](AGENTS.md) を参照してください。

## 必要なもの

| ツール  | バージョン                                                      |
| ------- | --------------------------------------------------------------- |
| Node.js | 26 以上                                                         |
| pnpm    | 12（`package.json` の `devEngines` で固定。違う版なら自動取得） |

## 起動

```sh
git clone https://github.com/assb-lab/crystal-atlas.git
cd crystal-atlas
pnpm install
pnpm dev
```

`http://localhost:4173` をブラウザで開いてください。

## ビルド・オフライン版

```sh
pnpm build
```

| 出力                                                                  | 用途                                                                  |
| --------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `dist/index.html`・`dist/assets/`・`dist/knowledge/`・`dist/records/` | DB・Workerを含めて静的Webサーバーに配置する版。相対パスで配信         |
| `dist/crystal-atlas.html`                                             | データ・JS・CSSを内蔵した単一HTML。ダブルクリックでオフライン利用可能 |

`dist/records/index.html` はJavaScriptなしで読める公開レコード索引です。対象・文献・主張など10種類の個別ページを実際にSSG生成します。アプリは `#atlas?kind=entity&id=...` 等で直接参照し、⌘Kから候補や模型にも移動できます。単一HTMLはgzip埋め込みのためDecompressionStream対応ブラウザが必要です。

[静的探索・配布・測定](docs/STATIC_EXPLORATION.md)、[文献抽出手順](docs/EXTRACTION_WORKFLOW.md)、[文献別分類](docs/CLASSIFICATION_SCHEMES.md)、[対称性の検証範囲](docs/SYMMETRY_VERIFICATION.md)、[全計画の対応表](docs/IMPLEMENTATION_PLAN.md)を参照してください。

`pnpm preview` でビルド結果を確認できます。`dist/` は生成物です。単一HTMLは `vp build --mode standalone` で、`vite.config.ts` の `standaloneHtml` プラグインが生成します。

## 機能

- **Family（分類）** — 構造を選ぶと、中央に文献体系ごとの所属パスを表示します。分類を選ぶと下位分類・所属構造へ進み、HSの回転系は表で比較できます。目次は話題別の編集ナビゲーションで、文献体系の違いと出典は保持します。
- **Symmetry（対称性）** — 左で系統を選び、中央の上位群→部分群の図から構造または枝を選択します。右で出典・設定・Wyckoff分裂・検証範囲を確認できます。枝の折り畳み、拡大、全体表示に対応し、共有する子構造は別の開いた親から到達できる限り残します。
- **関係を探索** — 構造名・組成・Strukturbericht記号の検索、20ファミリーの切替、SVGグラフの拡大／移動、構造・関係の詳細、一覧表示。⌘KまたはCtrl+Kで、現在のファミリーやタブをまたいだ全件検索を開けます。
- **比較と学習** — 2つの単位胞を同期回転・ズームし、格子定数、Wyckoff位置、サイト占有、構造間の直接の関係を比較。地図内の接続経路と12の学習ルート。
- **構造ラボ**：4つのfcc副格子の表示切替、12種類のプリセット、Canvasによる回転模型、T/O空隙占有率の数え上げ。
- **出典**：構造・関係ごとの文献箇所、印刷ページとPDFページの対応、手元のPDFのローカル関連付け、JSONデータ書き出し。

**220構造カード、283既存関係、32資料**を収録しています。201件の保存座標モデルと由来・未確認条件を保持し、画面の模式表示と区別します。うち**14関係**は文献確認済みの群–部分群関係です。Galasso の2冊で扱う構造に加え、トンネル・シアー酸化物と混合アニオン化合物を収録しています。収録の基準は、構造上の関係（比較・別の見方以外の関係）か、分類ビュー・派生図で他の構造とつながることです。比較だけでつながる構造や、固体電解質・リン酸塩・ケイ酸塩・ゼオライトのような用途・鉱物種でまとめたファミリーは収録していません。

派生矢印を持つ親構造は上段、派生構造は下段に自動配置します。「岡本佳比古の派生図」から、格子の貫入、四つのfcc副格子、充填面の規則化、岩塩・NiAs型からの派生、ブロック置換、層状シアー、Ir酸化物の関連構造を図番号別に探索できます。

単位胞と比較画面、構造ラボに、実格子方向のa・b・c、逆格子方向のa*・b*・c*、反対側からの−a・−b・−cの投影ボタンがあります。軸方向の投影では平行投影を使用し、単斜晶・三斜晶でも実格子と逆格子を区別します。比較画面では同じ軸名を各単位胞の格子に適用します。

Familyは「所属・分類」と「出典・詳しい説明」、Symmetryは「関係図」と「選択の詳細」を狭い画面で切り替えます。Familyの「構造・分類を探す」は構造・分類項目・体系の横断検索と目次を開きます。長い設定や模型の説明は詳細を展開して確認できます。Derivationの画面再設計は次の作業です。

## 開発コマンド

```sh
pnpm check     # 整形・lint（型情報を使うルールを含む）・型チェック。自動修正は pnpm exec vp check --fix
pnpm test      # ユニットテスト（vp test run）
pnpm catalog:scan # refsのPDF目録を再生成（Popplerが必要）
pnpm build:db  # 版固定のWASMで知識グラフDBを生成
pnpm test:db   # 実DB再オープン・照会・書き込み拒否の検証
pnpm build     # 型チェック後に配信版と単一HTMLを生成
pnpm e2e       # ビルド済みの dist/ に対するE2Eテスト
pnpm verify    # 上記すべてを順に実行
```

E2Eテストはインストール済みの Google Chrome を使います（ブラウザのダウンロード不要）。別のブラウザを使う場合は `PLAYWRIGHT_CHANNEL` を指定するか、`pnpm exec playwright install chromium` の後に `PLAYWRIGHT_CHANNEL=chromium` を指定してください。スクリーンショットは `test-results/` に保存されます。

## 読み方と限界

このアトラスは、全ての関係を一本の厳密なBärnighausen treeにしたものではありません。群–部分群、空隙占有、積層、反型、幾何学的な類似を区別しています。確認済み関係でも、未転記の基底・原点・位置変換がある場合は詳細に注記しています。

座標はプロトタイプ、文献の構造データ、計算緩和、平均構造、理想模型に区別しています。格子定数とサイトは採用した代表セルに対応します。比較ビューはセルごとに表示倍率を調整し、座標変換を行わずに回転を同期します。矢印と接続列は文献に基づく構造の関係を表します。

手元のPDFは Git 除外済みの `refs/` に置けます。アプリでは「参考資料とページ対応」から、ブラウザ内でPDFを関連付けます。文献目録・未調査範囲は「読み方・出典」で確認できます。再生成と台帳編集は[文献目録](docs/LITERATURE_CATALOG.md)を参照してください。参考資料の権利は各権利者に帰属します。このリポジトリのライセンスは未設定です。

「構造の分類」では、ペロブスカイト（A/Bサイト秩序・極性・層状ブロック・欠損）、Glazerの15回転系、Delmas積層、ハニカム、パイロクロア、Galasso（1970）の第2〜11章を選べます。39ビューは元のファミリーと重複する分類です。

CaMnTi₂O₆は293 Kの単結晶CIFと800 Kの回折平均セルを収録しました。O1・O2・O3・O4・P2・P3・OP4・T#2は単位胞で比較でき、O6・OPP9は分類表で文献を案内します。O2/O4の単位胞はAFLOWの積層プロトタイプで、実試料の欠損率を再現したものではありません。OP4や分裂Na位置は採用精密化の部分占有を表示します。

マップはウィンドウの残り幅・高さを使います。左右の「分類・検索」「構造の詳細」は開閉でき、デスクトップでは境界のドラッグ、または境界にフォーカスして左右矢印キーで幅を調整できます。開閉・幅はこのブラウザに保存します。狭い画面ではサイドバーを地図に重ねて開き、Escapeまたは背景のクリックで閉じます。

「全世代ツリー」が既定表示です。選んだ分類・ファミリーの親・子・孫・その先まで、世代制限なしで表示します。同じ派生段階は同じ高さに保ち、3列での折り返しは行いません。「選択系統」「この系統を表示」でも、選択構造の祖先と子孫を末端まで残します。構造を選ぶだけでは地図の中心や配置を変えません。

「この枝を畳む」で、選択構造の先だけを手動で折り畳めます。ほかの開いた親からも到達できる構造は残します。「この枝を再表示」または「全ての枝を開く」で復元します。折り畳みの案内は実際の派生矢印と区別し、隠れている構造数を表示します。「一覧」は折り畳みによらず選んだ分類・ファミリーの全構造を表示します。

接続線は曲線で描き、無方向の比較に矢印は付けません。長い図はドラッグ・四方向ボタンで移動し、「全体に合わせる」で俯瞰、「選択位置へ」で読める倍率に戻せます。
