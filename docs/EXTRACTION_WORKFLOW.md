# 文献抽出と調査範囲

`pnpm extract:propose --asset <SHA-256> --from <PDF頁> --to <PDF頁> --output refs/curation/<提案>.json` は既知の資産を範囲指定して処理します。選択可能なテキストはpdftotext、`--ocr --ocr-lang eng` 指定時の画像頁はpdftoppmとTesseractで処理します。必要な実行ファイルはローカルに用意します。追加言語は対応するTesseractデータが必要です。

提案には辞書・頁テキストのハッシュ、実行ツールと版、処理方法、出現位置を記録します。全文や画像は配布物へ入れません。出力先はignoredなrefs/curationに限定し、既存ファイルを上書きしません。前後のPDFハッシュを照合し、処理しただけでは台帳・正規データ・採否を更新しません。原表記の一致は同定ではなく、関係も自動採用しません。印刷頁は明示アンカーがない限り未知です。書誌対応が候補の資産は抽出できてもDB登録用batchを生成しません。

今回の確認範囲は岡本PDF2–4とMüller2013 PDF21です。手動候補と、岡本PDF4の実際の辞書抽出37件を別runで登録しています。機械候補は未判断です。図・表・索引も別の調査状態を持ちます。後続の分類照合でHoward–StokesのPDF4も範囲登録したため、母数3760 PDF頁のうち本文5頁が調査中、3755頁が未調査です。図・表・索引は別の母数内状態を保持します。「対象なし」は当該頁で確認した表・索引だけに適用しています。処理成功・文字数・候補0件を網羅調査の完了と扱いません。

画像PDFの先頭頁を英語OCRし27件の辞書候補を取得しましたが、書誌同一性が未確認のためローカル提案に留めました。Mitchell書籍の存在確認と、そのPDFの版・同一性確認は別です。全132頁は未調査です。

候補の修正・採否はCandidateDecisionの追記とSupersedesDecisionで履歴を保持します。元の候補と旧判断を書き換えず、現在の判断を照会します。画面は処理範囲ごとに候補と現在の採否を集計し、旧版も表示します。採用されない候補からRefersToや科学的Assertionを生成しません。

CIはPDFを必要とせず、メタデータ・実DB全行とブラウザを検証します。ローカルの再抽出と頁画像照合は別の作業です。
