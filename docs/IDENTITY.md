# 対象の同定と座標モデル

Issue #31では、構造モチーフ・格子型・一般の構造型・原子種を割り当てたプロトタイプ・化学物質・物質の相・座標モデルを区別します。名前や化学式だけでは統合しません。旧カードID・関係・座標は保持します。

代表例はTiO₂です。物質の組成定義を`material:TiO2`、資料が多形として記載するルチルとアナターゼを`phase:TiO2:*`、AFLOWの参照プロトタイプを`prototype:TiO2:*`とします。旧`rutile`と`anatase`は一般の構造型として残します。phase_of／has_structure_type／prototype_of_typeは独立した根拠付きのdescription主張で、同一性のリンクではありません。

根拠はAFLOWの[Rutile](https://aflow.org/p/A2B_tP6_136_f_a-001/)と[Anatase](https://aflow.org/p/A2B_tI12_141_e_a-001/)です。多形の存在と参照構造を確認した範囲であり、測定温度・圧力・実試料を特定しません。温度・圧力はnullと未転記の状態を保持し、室温・常圧や安定領域を仮定しません。未分離の旧カードは件数を表示し、今後の範囲別照合へ残します。

全既存座標モデルには`ModelContext`と`ContextFor`を追加します。元のStructureModelは変更せず、kind、原典のラベル／URL、採用セル・空間群番号・分率座標・部分占有の情報を保持します。設定と原点、温度・圧力、精密化／計算緩和の確認状態は未転記・未確立です。prototypeを実験精密化済みと表示せず、literatureもそれだけで実測値へ昇格しません。

既存アナターゼ模型は参照プロトタイプを例示する`IllustratesPrototype`で接続します。AFLOWは過去の設定1→2の酸素座標の訂正を明記しているため、その注意と既存模型の数値再照合が未実施であることを表示します。相や実試料の精密化モデルとして接続しません。

3Atlasの対象プロフィールで種類・物質／相／型への接続・出典・模型の由来を共通に閲覧できます。実DB照合と両配布形式のdesktop／390pxで確認します。
