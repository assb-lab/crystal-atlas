# 文献別の分類体系

ClassificationScheme → SchemeItem → Entityが体系の語彙を保持し、ClaimInSchemeで所属・包含のAssertionを体系へ束ねます。SchemeDocumentは参照する文献を指定します。同名項目でもIDと体系が別なら統合しません。所属は複数持てます。分類矢印を派生操作へ流用しません。

既存ファミリーは編集上のナビゲーションです。カードの一般参照を所属根拠へ移しません。既存分類の参照集合が単一文献ならその文献の既存収録体系、複数なら文献集合に基づく編集上の整理として保存します。すべて未再照合のままです。個々の文献が、その整理全体を主張しているとは扱いません。

Howard–Stokes (1998) Table 1（印刷785頁、PDF4頁）の全頁画像から、無回転を含む15回転系と理想空間群を別体系へ転記しました。Glazerの原論文の23系と同じ表ではありません。理想立方ペロブスカイトだけを無回転項目へ接続し、実物質の秩序や極性変位をこの根拠で一括分類していません。セル変換の機械検証はこの分類作業の対象外です。

画面は全体系・全項目と所属／包含件数を示し、選択対象の別体系での所属を並べます。根拠を開くか具体例からDerivationへ移動できます。分類・包含の不正参照、循環、根拠欠落はレジストリ追加前に拒否します。実DB検証は物理テーブルの全行と体系・複数所属の固定クエリを実行します。

文献目録もHSのPDF4だけを本文・表は調査中、図・索引は当該頁に対象なしとして更新しています。残るPDF1–3、5–9は未調査です。項目の限定照合を頁全体の網羅照合へ昇格させません。
