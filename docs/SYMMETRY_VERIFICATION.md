# 対称性対応と検証の境界

SymmetryMappingはAssertionを修飾し、上位／下位の記号・設定、t/k/i、指数、基底・原点と規約、Wyckoff分裂、文献確認／転記の状態を保存します。MappingEvidenceは原典箇所、MappingModelは宣言した理想模型、SymmetryValidationはその模型に対する再現可能な計算を保存します。未知値はnull／unknownです。既存14 strict関係は設定・数値を未転記のまま移行し、検証済みへ変更しません。

Müller2013 §1.2 Fig.1.1（印刷4頁、PDF21頁）の全頁画像で、diamond→zinc blendeの下向きt2と8a→4a+4c、C/Sの(0,0,0)、Znの(1/4,1/4,1/4)を照合しました。二つの登場記録と関係を限定採用しています。同じ立方セル・原点を用いるP=I,p=0は本文と図からの明示した解釈です。通常の別の原点で8a=(1/8,1/8,1/8)となる設定へ転用しません。番号227/216は標準記号との対応で、独立した空間群番号同定の計算ではありません。

検証器は相対長さの立方セルに、F心の4点と(1/4,1/4,1/4)を加えた4点を置きます。座標を4倍した整数で、48個の符号付き軸置換と可能な1/4刻みの並進を列挙し、位置集合を保つ192演算、そのうちS/Znの区別を保つ96演算を得ます。整数並進を法として群の閉包・単位元・部分群包含・共通の並進4剰余類と4+4の軌道分裂を検証します。有限個の可逆変換の集合で閉包と単位元があるため逆元も集合内です。指数2のt型に整合します。

これは宣言した理想位置集合に対する厳密な代数検証です。全設定の空間群同定、実験精度、他の既存座標模型、実相転移や化学反応を検証しません。一般の行列やk/i型をこの限定検証器へ渡すと拒否します。文献確認、セルの解釈、計算の証拠は分けて表示します。

Bärnighausen treeは既存14関係と新たな原典別対応をすべて表示し、上位から下位へ向けます。出典別の別説明、共有対象、枝ごとの折り畳みを保持し、深さ制限はありません。Derivationには同じ図の原子ラベルを二分する説明を独立Assertionとして登録し、ExplainsSymmetryOfで対応付けています。岡本の逆向きのラベル同一視とは統合しません。
