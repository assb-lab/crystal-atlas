# 文献目録とページ調査台帳

「読み方・出典」→「文献目録とページ調査台帳」から、LadybugDBに収録した資産と未調査範囲を確認できます。3つのAtlasと同じ読み取り専用DBです。PDFや本文は配布しません。

## 再生成

走査にはPopplerの`pdfinfo`が必要です（macOSでは`brew install poppler`）。通常のビルド・アプリ利用にはPopplerやローカルPDFは不要です。

```sh
pnpm catalog:scan
# 任意の入力ディレクトリと出力先を指定する場合
pnpm catalog:scan /path/to/local/refs /path/to/catalog.json
pnpm test:db
```

既定入力はGit除外の`refs/`、出力は公開用メタデータの`src/data/literature-catalog.json`です。サブディレクトリを含むPDFだけを走査し、シンボリックリンクを辿りません。相対パスのUnicode表現を保持し、ファイル名の候補比較時だけNFC正規化します。

同じ内容のコピーはSHA-256で一つのAssetにまとめ、全配置パス・役割を残します。主資料・補足資料は名前、curationは配置による初期ラベルです。読取不能なPDFもSHA・バイト数を残し、ページ数と終端は`null`にします。ファイル読み出しの失敗、走査中の変更、pdfinfo未導入では失敗し、既存JSONを置換しません。

同じファイル集合・既存台帳・pdfinfo版なら同じJSONになります。時刻・絶対パス・本文は含みません。目録は現在存在するファイルの一覧です。最後のコピーが削除された資産は一覧から外れ、旧版はGit履歴に残ります。

## 書誌と実ファイル

`Document`は既存出典IDの書誌、`Asset`は実ファイルです。版の記述がない書誌を自動補完しません。`mapping.state=candidate`はファイル名候補で、`CandidateAsset`で接続します。`unmatched`は書誌未対応です。

タイトル・著者・版を実資料で確認した後だけ`confirmed`に変更し、出典IDを一つ、`basis`に確認箇所・方法を記します。`identification`に調査者・日付・確認方法・資料区分、各項目のPDF頁と確認結果、未確認事項を記録します。確認済みにはタイトル・著者と出版情報の確認が必要です。補足資料ではSupporting Informationの明記を別に確認します。この場合だけ`HasAsset`を生成します。補足PDFは別Assetとし、対応根拠に補足資料であることを記します。確認済み対応と台帳は同じSHAにだけ再利用し、同じパスの別ファイルには引き継ぎません。未確認候補は全配置ファイル名から再計算します。

既存`SourceSpan`の印刷頁・PDF頁は保存しますが、資産との対応を未照合なので`LocatedIn`は生成しません。ブラウザでのPDF関連付けも、書誌・版の確認とは別です。

## 台帳の編集形式

各Assetの`coverage`は1始まりのPDFページ範囲です。全ページを隙間・重なりなく覆い、本文・図・表・索引それぞれに`not_started` / `in_progress` / `reviewed` / `not_applicable`を記録します。初期値は全て未調査です。「図がない」なども調べるまでは未調査とします。

一部を調査したら範囲を分割します。PDF 1–10の本文を照合した場合、1–10と11–終端を分け、前者の本文だけを`reviewed`にします。`note`に担当者・調査日・対象と結果を記してください。未調査以外は非空の注記が必要です。印刷頁対応は`printedPageMapping`に別途記し、未確認は`null`にします。未知の終端への照合済み登録は拒否します。

`CoverageReview`→`Reviews`→`Asset`で接続します。全項目未調査の範囲は`status=not_started`、何かを記録した範囲は`recorded`です。後者は全項目完了を意味せず、画面には各項目の状態を表示します。編集はJSONのレビューを経由し、ブラウザ内編集は本Issueの範囲外です。

`ProcessingRun`は固定IDで、このスナップショットの目録生成活動を記述します。`CataloguedBy`で資産に接続し、時刻付きの履歴イベントとしては扱いません。抽出・科学的照合の実行を捏造せず、`ByRun`や`Mention`は作りません。調査記録がある同一SHAでページ数が変わった場合は、台帳を黙って初期化せず停止します。

初回は16ファイル・16資産・3,760 PDFページ、ファイル名候補9資産・書誌未対応7資産です。全範囲未調査で、網羅率・調査完了率は算出しません。構造候補抽出・名寄せ・構造型／物質／相の分離は後続Issueです。

## 書誌識別の確認

Issue #18で16資産に識別記録を追加しました。15資産は既存／追加書誌へ対応確認済み、前付けを確認できない本文抜粋1資産は未解決です。本体・補足・本文抜粋の区分と制限は画面で閲覧できます。既存Müller 2013のシリーズ名を、PDF 3頁の表記に基づきIUCr Texts on Crystallography 18へ訂正しました。

これは本文・図表の構造抽出とは別の確認です。CoverageReviewは全範囲未調査を維持し、既存のSourceSpanへLocatedInを付与していません。未解決資料も同じSHAと候補集合なら識別注記を再スキャンで保持します。識別済み資産のページ数が変わった場合も停止します。

後続の抽出範囲は[構造抽出パイロット](EXTRACTION_PILOT.md)を参照してください。

## 構造抽出の候補

Issue #20ではK資産のPDF 2–3頁に限定して、登場記録10件と関係候補10件を追加しました。目録でこの資産を選ぶと「この資料の構造抽出候補」から原表記・登場位置・既存構造への対応候補・既存関係との照合候補を確認できます。すべて対応未確定で、本文・図の台帳は調査中です。表・索引は対象2頁で不在を確認し、範囲外を未調査で残しています。書誌識別の確認と、構造情報の科学的照合の完了は別です。
