# 派生操作・ラベル写像・順序付きの説明

Issue #32で、保留されていた同種原子操作3件を再照合しました。Cs/Cl、Na/Cl、Zn/Sの区別を共通の抽象ラベルXへ写し、理想配置をbcc、単純立方、ダイヤモンド型として読み直す操作です。KのPDF 3頁の本文と、参照される図1・図2が根拠です。Xを特定の元素と同一視せず、実際の元素変換・合成・相転移とは区別します。

`LabelMapSpec`に入力ラベル・出力ラベル、理想配置点の集合を保つ条件、到達最小セルの対応が未検証であることを明示します。原表記・初回の保留・逆向きの既存説明を残し、後続判断から採用結果を接続します。新しい群–部分群の対応や数値セル変換は作りません。現在20判断は採用20、履歴27判断には初回の保留7を保持します。専門家の独立レビュー・座標検証は未実施です。

`OperationDefinition`は、貫入、占有、欠損、規則化、置換、ラベル同一視、積層、歪み、ブロック置換の語彙と必要な記録を整理する編集上の定義です。`VocabularyExample`は参照例を示し、未再照合の既存記述を採用済みへ変更しません。個々のAssertionの根拠と検証状態は別に表示します。

`recipe:fcc-nacl-sc`は、根拠のある「fcc→岩塩型の貫入」と「岩塩型→単純立方のラベル写像」を組み合わせる編集上の構築レシピです。HasStepのordinalで2手順を保持し、ComposesAssertionで個別説明へ接続します。個々の根拠を保持しますが、レシピ全体が文献で一連の過程として提示されたことや、全体のセル整合・実行可能性を検証したことは主張しません。

DerivationRouteには文献図の提示順と編集上のレシピを区別して保持します。文献図は枝・共有する子孫を含み、配列順を合成・相転移の時間順に読み替えません。画面は全登録経路を選択でき、全メンバーを省略せず表示します。個別手順から操作・根拠のレコードへ移動できます。既存の全世代充填表示・折り畳み・共有子孫は維持します。
