# 横断探索・直接参照・静的配布

検索は従来の構造名・別名・組成・空間群と、DBの公開主要レコード10種類を対象にします。対象／分類項目、文献、主張、操作の定義／手順、分類体系、登場／関係候補、座標モデル、文献資産です。選択範囲と総件数を明示し、50件ずつ追加表示できます。取得クエリで黙ってLIMITを掛けません。補助的な根拠位置、検証活動、採否履歴等は関連レコードや配布dataset.jsonから参照します。検索対象外の物理ノードを検索済みと扱いません。

`#atlas?kind=entity&id=phase%3ATiO2%3Aanatase` のような直接参照でレコードを開きます。対象から3Atlasとモデル由来、主張から端点・出典・該当Atlas、文献からPDFのローカル関連付け、候補から元記録・採否履歴へ移動できます。未知IDは未登録と表示します。IDをURLで渡してもクエリには値としてバインドし、テーブル名は固定の許可集合から選びます。

表示切替やガイドへの移動で、各Atlasの対象・選択主張・対象履歴、選択した分類体系、経路・操作語彙、treeの枝折り畳みを保持します。これらはページ内のナビゲーション状態です。再読み込みではURLの直接参照を復元し、折り畳み全体や閲覧履歴の永続保存は行いません。充填ツリー自身の選択・レンズ・共有子孫・履歴・カメラは別Atlasの操作で変更しません。

`scripts/ssg.ts` はビルド時の同じ知識データから、公開主要10種類の全1831レコードと索引、計1832 HTMLを実生成します。単なるSPAのfallbackではありません。対象340、文献32、主張960、操作定義9、操作手順194、分類体系10、登場候補55、関係候補14、座標モデル201、文献資産16です。静的ページは出典・状態・未確認事項とアプリへの相対リンクを含み、JavaScript・WASMなしで読めます。個別URLはIDを安全なファイル名へ可逆変換します。単一HTMLにSSGページ群は同梱せず、同じレコードを内蔵DBから閲覧します。

静的配信はDB／JS module／Workerの内容ハッシュ付き名と、再検証するmanifestを使います。配信先のサブパスで動作します。DBは常にreadOnlyで開き、長さ・版・Web Crypto利用時のSHA-256を照合します。JSONへの暗黙の代替照会はありません。読み込みやWorkerの失敗は表示し、終了してから再接続します。初回配置、接続、RPC、待機中の照会にも期限を設けています。

単一HTMLのDB／module／Workerはgzip後にbase64化し、レコード閲覧時にDecompressionStreamで展開します。展開後のDBに従来と同じハッシュ照合を行います。全文PDFや画像は含みません。DecompressionStreamがない環境は理由を表示して停止し、別データで成功したように見せません。仕様は[MDN DecompressionStream](https://developer.mozilla.org/en-US/docs/Web/API/DecompressionStream)を参照してください。

# 測定と実際に検証した範囲

Node 26.13.0、pnpm 12.18.0、Apple M4 Max／36 GiBで実測しました。ChromeのCDPでページのCPUを4倍に遅延し、配信版のページ対象に16 Mbps（2,000,000 byte/s）・遅延80 msを設定します。単一HTMLはネットワークを無効化し、CPU遅延だけを設定します。[Playwright CDPSession](https://playwright.dev/docs/api/class-cdpsession)を使用し、`tests/e2e/performance.spec.ts --workers=1` で測定を再生成できます。各テストのmeasurements.jsonにはブラウザ版・資産サイズ・Resource Timing・初期化・全照会時間を保存します。

DBの未圧縮サイズ18,759,680 bytes、Worker 24,537,566 bytes。単一HTMLは旧方式の約57.5 MBから約7.06 MBへ減りました。配信サーバーのHTTP圧縮と、HTML内のgzipは別です。ファイルの未圧縮長を通信量として扱いません。

Chrome 157.0.8103.38。初期化と分類表示の時計の始点は別です。生の測定値・ハッシュは[測定記録](validation/2026-11-09-distribution.json)を参照してください。配信版のResource TimingでDB約0.45 MB、Worker約4.27 MBのHTTP圧縮後サイズを確認しました。

数値は一回のローカル再現例で、性能保証ではありません。照会時間はキュー待機・Worker RPC・結果受け取りを含み、SQLエンジンだけの時間ではありません。CDPのページ対象への制限がWorkerのCPUや全通信へ同じように継承されるかは未確立です。実際の低メモリ端末・携帯端末・他ブラウザは未測定です。初回UIのJSは約0.8 MBのため、ビルドの大きなchunk警告は残ります。WASMは最初のレコード探索まで起動しません。

配信版／file://ネットワーク無効、desktop／390px／既存320px、SSGのJavaScript無効、サブパス、版不一致、DB破損、起動後のWorker停止からの再試行、gzip非対応の明示をE2Eで検証します。単一HTMLに外部CDNやバックエンドは不要です。
