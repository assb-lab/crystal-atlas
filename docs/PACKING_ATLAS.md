# 基本充填を起点にしたアトラス（Issue #9）

## 何を統一したか

従来の20ファミリー、39横断分類、8文献フローは別々の結晶分類体系ではなく、同じ構造データを取り出す入口だった。新しい標準探索画面は **bcc / ccp / hcp** を入口とし、空隙占有・規則化・空孔・変位・積層の説明を経て具体物質へ進む一つの主系統を表示する。横断分類と岡本資料の説明経路はこの系統への索引であり、選択しても祖先を切断しない。

「主系統」は編集上選んだ読み順であって、唯一の結晶学的分類・熱力学的相転移経路ではない。別の導出、反型、部分網の類似、実際の群–部分群関係は元の文献関係を重ねて確認する。

## 結晶学上の区別

- bcc / fcc は cI / cF に原子基底を置いた基本配列として扱う。B2はbcc由来の色分けでもP格子である。
- hcpはブラベー格子そのものではなく、hP＋2原子の基底。子構造まで全て単純AB積層とは主張しない。
- ペロブスカイトの入口は **AとXを合わせた1:3混合ccp**。Xだけの最密充填ではない。Bが占めるX₆八面体孔は全O孔の1/4（West §1.17.7, pp.61–62; 岡本 図10）。
- ルチルには岡本 図19の **B2からのTiO₆ブロック置換という幾何学的説明** を主経路として選んだ。「ルチルはbcc格子」「hcpの部分群」という主張ではない。NiAs/CaCl₂を経由する別説明や対称性の関係は文献レイヤーに保持する。
- パイロクロアは欠陥蛍石の平均配置からA/Bと空孔を秩序化し、変位を加える記述。Y₂Ti₂O₇、La₂Zr₂O₇、Cd₂Re₂O₇は具体例の枝に置く。原資料の逆向きの平均化の矢印は変更しない（West §1.17.12, pp.85–89）。
- Bサイト1:1と1:2、RPのn=1/2/3、Magnéliのn=4/5は並列の配列・系列メンバー。異なる具体物質を親子として直列につながない。

## データ層

`DATA`（220構造、283文献関係、座標・出典）はそのまま保持する。データハッシュ、元のID、模型、出典位置、分類表を変更していない。

`src/data/packing.ts` は明示的な主経路と説明用の整理ノード。`src/lib/packing.ts` が検証・祖先補完・折畳み・順位・文献関係の重ね合わせを担当する。旧familyや矢印方向から親を自動推測しない。

| 分類      | 表示と意味                                      |
| --------- | ----------------------------------------------- |
| packing   | 基本配列                                        |
| structure | 構造型・既存の代表模型                          |
| material  | 具体組成・相。主系統では必ず葉                  |
| topic     | 読むための整理の枝。結晶相・空間群・CIFではない |

主経路のリンクは `derive`（記述上の派生）、`example`（具体化）、`topic`（案内）に区別する。派生リンクには既存の文献関係ID `evidence` または出典を付ける。中間の整理枝は文献の記述を横断してまとめた編集上のグループであり、単一の空間群を割り当てない。

文献関係は元の `a`, `b`, `undirected`, `strict` を変更せずに重ねる。`strict` は重ねた文献関係にだけ適用し、主系統の全矢印を群–部分群と誤認させない。

## 収録範囲と未解決事項

元の220構造のうち、bcc側22、ccp側141、hcp側32、補助骨格側25。主要三系統の合計は195構造。39個の説明用整理ノードは実在構造数に数えない。

補助骨格にはBaAl₄、CeMg₂Si₂、ガーネット、開いた四面体骨格等を残す。**AlB₂、Na₃As、MoAlB、Ti₃SiC₂、CuAl₂** の5件は、今回検証できた資料から主経路を確定せず「親経路未検証」に保持した。未収録・無関係という意味ではない。無理に三系統に押し込むより、追加の根拠に基づいて後で移す。

既存ノードには構造型と代表物質を兼ねたものがある。このPRは全220件を新しいCIFデータベースへ置き換えるものではなく、参照模型の意味を保持しながら主経路を整理する変更である。新規のSnO₂/MgF₂等の構造データは追加していない。

## 画面と操作

初回は4入口を明示的に折り畳む。カードに隠れている項目数を示し、「全世代を展開」で全部を表示できる。系統ナビゲーションで枝を選ぶと、その枝の全世代と全祖先を表示する。広い図を自動的に極小へ縮小せず、読める倍率で入口を示す。「全体に合わせる」で全景、「選択を等倍で」で詳細へ戻る。

文献/分類の索引は全て同じボタン形式。対象以外の祖先は文脈ノードとして薄く表示する。Glazer・Delmas等の比較表はマップ上の開閉可能な表に残す。出典強調はノードを削除せず強弱のみを変える。

各ノードはクリック/Enter/Spaceで詳細、ダブルクリックでその先を展開。パン、ズーム、手動の枝折畳み、検索、戻る、モデルの比較、実/逆格子投影、参考資料参照、ラボ、単一HTMLのオフライン動作を継続する。
